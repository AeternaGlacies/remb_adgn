Les réglages sont sauvegardés uniquement dans ce navigateur. Sur GitHub Pages, ils ne sont pas partagés entre les utilisateurs.

Pour fixer la même adresse pour tout le monde, modifiez les constantes DEFAULT_EMAIL et DEFAULT_ACTIVITIES dans app.js avant la publication. Ne saisissez jamais de mot de passe dans ce site.
